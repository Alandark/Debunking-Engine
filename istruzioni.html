Istruzioni per la creazione delle API Key

Introduzione

Per utilizzare tutte le funzionalità basate sull'Intelligenza Artificiale integrate in Debunking Engine, è necessario configurare almeno una chiave API valida.

L'applicazione supporta due tipologie di chiavi:

  • API Key Gemini (Obbligatoria) – necessaria per il funzionamento dei servizi AI principali.
  • API Key Google Fact Check (Opzionale) – utilizzabile per integrare le verifiche con il database pubblico di fact-checking di Google.

Senza una Gemini API Key il sistema non sarà in grado di elaborare richieste, analizzare contenuti o generare report di verifica.

La Google Fact Check API Key, invece, è facoltativa: la sua assenza non impedisce il funzionamento dell'applicazione, ma limita alcune funzionalità avanzate di verifica automatica.

1. Creazione della Gemini API Key (Obbligatoria)

Per ottenere una chiave API Gemini è necessario possedere un account Google.
La documentazione ufficiale è disponibile al seguente indirizzo:
https://ai.google.dev/gemini-api/docs/api-key?hl=it

Procedura passo-passo

  1. Accedere a Google AI Studio
    Aprire il link indicato sopra e accedere con il proprio account Google. Se richiesto, completare la procedura di accesso o di registrazione.
  2. Accedere alla sezione API Key
    Una volta entrati in Google AI Studio, individuare la sezione dedicata alla gestione delle chiavi API. Google potrebbe mostrare direttamente il pulsante per la creazione di una nuova chiave oppure richiedere la selezione di un progetto Google Cloud.
  3. Creare una nuova chiave
    Selezionare l'opzione "Crea API Key" (o "Create API Key"). Qualora venga richiesto: selezionare un progetto esistente oppure creare un nuovo progetto Google Cloud. Al termine della procedura Google genererà automaticamente una nuova chiave API.
  4. Copiare la chiave generata
    La chiave verrà mostrata sotto forma di una stringa alfanumerica univoca. Esempio:
    AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
    Il valore mostrato nell'esempio è puramente illustrativo. La chiave reale sarà differente.
  5. Configurare Debunking Engine
    Tornare alla schermata principale di Debunking Engine. Nel campo API Key Gemini (Obbligatoria) incollare la chiave appena generata. Una volta inserita correttamente, l'applicazione potrà utilizzare i servizi di Intelligenza Artificiale forniti da Gemini per l'analisi e la verifica dei contenuti.

2. Creazione della Google Fact Check API Key (Opzionale)

La Google Fact Check API consente a Debunking Engine di interrogare il database pubblico di verifica dei fatti messo a disposizione da Google, contenente migliaia di fact-check provenienti da organizzazioni e verificatori indipendenti di tutto il mondo.

L'utilizzo di questa API è facoltativo. Debunking Engine può funzionare correttamente anche senza questa chiave, ma la sua configurazione permette di ampliare le fonti consultate durante alcune operazioni di verifica.

La documentazione ufficiale è disponibile al seguente indirizzo:
https://developers.google.com/fact-check/tools/api?hl=it

Cos'è la Fact Check API

La Fact Check API fornisce accesso al database di verifica dei fatti gestito da Google Fact Check Explorer. Attraverso questa interfaccia è possibile effettuare ricerche su affermazioni, notizie e dichiarazioni che sono già state analizzate da organizzazioni di fact-checking riconosciute.

Quando configurata all'interno di Debunking Engine, questa API consente al sistema di integrare i risultati delle proprie analisi con eventuali verifiche già pubblicate nel circuito internazionale del fact-checking.

Procedura passo-passo

  1. Accedere alla documentazione ufficiale
    Aprire il seguente indirizzo: https://developers.google.com/fact-check/tools/api?hl=it. Effettuare l'accesso con il proprio account Google se richiesto.
  2. Creare o selezionare un progetto Google Cloud
    Per utilizzare la Fact Check API è necessario disporre di un progetto Google Cloud. Se non si possiede già un progetto: Accedere alla Google Cloud Console, selezionare Nuovo Progetto, assegnare un nome al progetto e completare la creazione. Se si dispone già di un progetto attivo, sarà possibile utilizzarlo senza crearne uno nuovo.
  3. Abilitare la Fact Check Tools API
    Dalla pagina della documentazione o dalla Google Cloud Console, individuare la sezione dedicata all'attivazione dell'API. Selezionare l'opzione per abilitare la Fact Check Tools API all'interno del progetto scelto. L'operazione potrebbe richiedere alcuni secondi per essere completata.
  4. Generare una API Key
    Una volta abilitata l'API: Aprire la sezione Credenziali della Google Cloud Console. Selezionare Crea Credenziali. Scegliere Chiave API. Attendere la generazione automatica della chiave. Google mostrerà una stringa alfanumerica simile alla seguente:
    AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
    Il valore mostrato è soltanto un esempio illustrativo.
  5. Copiare la chiave
    Una volta generata la chiave: Copiarla integralmente. Verificare che non siano presenti spazi aggiuntivi all'inizio o alla fine. Conservare la finestra aperta fino al completamento della configurazione.
  6. Configurare Debunking Engine
    Tornare alla schermata principale di Debunking Engine. Nel campo API Key Google Fact Check (Opzionale) incollare la chiave appena generata. Una volta configurata, il sistema potrà utilizzare il database Google Fact Check come fonte aggiuntiva durante le operazioni di verifica e analisi delle notizie.

3. Note sulla Sicurezza delle API Key

La sicurezza delle API Key rappresenta un aspetto fondamentale per l'utilizzo corretto di Debunking Engine. L'applicazione è stata progettata seguendo un modello di funzionamento che minimizza l'esposizione delle credenziali degli utenti e non richiede la memorizzazione delle chiavi su server esterni gestiti dal progetto.

Come vengono gestite le API Key

Quando un utente inserisce una API Key all'interno di Debunking Engine, la chiave viene utilizzata esclusivamente dal browser dell'utente per comunicare con i servizi selezionati.

Le API Key non vengono archiviate nei file pubblicati del progetto, non vengono incorporate nel codice sorgente dell'applicazione e non vengono distribuite insieme al sito web. Questo significa che il repository pubblico contenente l'applicazione non include alcuna credenziale privata.

Pubblicazione dell'applicazione e protezione delle chiavi

Debunking Engine è una applicazione web di tipo client-side. Quando il sito viene pubblicato su GitHub Pages o su un altro servizio di hosting statico, vengono distribuiti esclusivamente:

  • il codice dell'applicazione;
  • le risorse grafiche;
  • i file necessari al funzionamento dell'interfaccia.

Le API Key degli utenti non fanno parte di tali file e non vengono pubblicate insieme al progetto. Anche nel caso in cui una persona esamini il codice sorgente della pagina o scarichi l'intero repository, non potrà visualizzare le API Key utilizzate dagli utenti.

Isolamento tra utenti

Ogni utente utilizza Debunking Engine attraverso il proprio browser e il proprio dispositivo. Le chiavi inserite da un utente rimangono associate esclusivamente alla sessione e all'ambiente locale del browser utilizzato.

Di conseguenza:

  • gli utenti non possono visualizzare le API Key di altri utenti;
  • le chiavi non vengono condivise tra dispositivi differenti;
  • ogni installazione del browser mantiene i propri dati separati dagli altri.

L'utilizzo dell'applicazione da parte di un utente non consente in alcun modo l'accesso alle credenziali inserite da altri utilizzatori del servizio.

Cosa succede quando un utente visita il sito

Quando viene aperto il link del sito accade quanto segue:

  • Il browser dell'utente scarica e carica il file index.html del progetto.
  • L'applicazione richiede l'inserimento della propria API Key.

Ogni browser funziona in modo completamente isolato rispetto agli altri utenti. Questo significa che la API Key inserita viene salvata esclusivamente nel browser locale dell'utente, nel database "localStorage" (ad esempio su Chrome, Firefox o Edge).

Questa informazione non viene inviata al server né condivisa con altri utenti. Di conseguenza, l'accesso allo stesso link da parte di un altro utente o da un dispositivo differente non consente alcuna condivisione dei dati: ogni browser mantiene un ambiente indipendente e non ha accesso a informazioni salvate altrove, incluse eventuali API Key.

Rimozione delle API Key

Debunking Engine consente in qualsiasi momento di eliminare le API Key precedentemente inserite. Quando una chiave viene rimossa attraverso il pulsante ✖ nell'interfaccia dell'applicazione, essa viene eliminata dal browser dell'utente e non rimane associata al sito.

Poiché le chiavi non vengono archiviate su server centrali, la loro eliminazione comporta la rimozione completa delle credenziali dal dispositivo utilizzato.

Conclusioni

Debunking Engine è stato progettato per evitare la pubblicazione e la distribuzione delle API Key all'interno del codice dell'applicazione. Le credenziali vengono gestite localmente dal browser dell'utente e non sono incluse nei file pubblicati online.

Questo approccio riduce significativamente il rischio di esposizione accidentale delle chiavi e consente agli utenti di mantenere il pieno controllo delle proprie credenziali durante l'utilizzo della piattaforma.
